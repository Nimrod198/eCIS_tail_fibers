# eCIS_tail_fibers
How do bacterial extracellular Contractile Injection Systems bind target cells?
A remarkable diversity of receptor binding domains

Nimrod Nachmias1,*, Zhiren Wang2,*, Feng Jiang2,#, and Asaf Levy1,#

1 Department of Plant Pathology and Microbiology, Institute of Environmental Science, The Faculty of Agriculture, Food, and Environment, The Hebrew University of Jerusalem, Rehovot, Israel

2 NHC Key Laboratory of Systems Biology of Pathogens, Key Laboratory of Pathogen Infection Prevention and Control (Ministry of Education), State Key Laboratory of Respiratory Health and Multimorbidity, National Institute of Pathogen Biology, Chinese Academy of Medical Sciences & Peking Union Medical College, Beijing, China

**Abstract**:
Extracellular contractile injection systems (eCIS) represent a diverse family of bacteriophage tail-derived protein toxin delivery complexes in prokaryotes. eCIS are vital for microbial interaction with hosts and they use tail fiber proteins for target cell binding. However, the identity of the tail fiber proteins and their target cells are unknown. Here, we conducted a comprehensive exploration of eCIS tail fiber genes, providing insights into their remarkable diversity, target cells, functional adaptations, and intriguing evolutionary dynamics. We identified 3,445 eCIS tail fiber proteins found in 2,585 eCIS loci from 1,069 microbes. These fibers can be categorized by five new N-terminal domains responsible for tail fiber attachment to eCIS baseplates. Importantly, we leveraged structure prediction to divide the fibers into 276 structural clusters and dissected over a thousand domain fold families which seem to facilitate glycan and protein binding on the surface of potential eukaryotes or bacterial targets. These domains are likely acquired from diverse genomes of eukaryotes, bacteria, and viruses. Finally, we experimentally showed that the tail fibers from Paenibacillus eCIS can bind and direct effector injection into THP1 murine monocytes, and may bind D-mannose. This study reveals the exceptional diversity of eCIS target specificity determinants, suggests new eCIS target cells in Nature, and provides thousands of proteins that adhere to different cell types.

**Code oparation manual:**
**Domain_finder_mmseq_opt.sh:** automates a bioinformatics pipeline for de novo protein domain discovery and analysis from a single FASTA file. It operates by performing an all-vs-all blastp search, clustering the resulting sequences with cd-hit and mmseqs, building cluster-specific Hidden Markov Models (HMMs) with hmmbuild, and finally annotating domains using hmmscan against both the custom-built and Pfam databases, with results processed by cath-resolve-hits and custom Python scripts. The environment requires Bash, Python 3, and the following bioinformatics tools: NCBI BLAST+, CD-HIT, MMseqs2, Clustal Omega, HMMER, and CATH-Resolve-Hits.

**casette_search.py**: command-line tool that searches for specified Pfam domains within a directory of .pfam annotation files corresponding to a given list of genomes. To run the script, provide a comma-separated list of Pfam IDs, a file containing genome IDs, the directory of .pfam files, and an output file path. The script will parse each relevant annotation file, identify all occurrences of the specified Pfam domains, and write the findings—including genome ID, gene ID, Pfam ID, and description—to a tab-separated (TSV) output file. The script requires Python 3 and the tqdm library, which can be installed via pip.

**casette_search_clustering.py** : functions as a command-line tool to identify and analyze gene clusters from a TSV file containing gene annotations. It operates by first reading gene data, then grouping genes into clusters based on their genomic proximity, defined by a maximum intergenic distance. Each potential cluster is validated by ensuring it contains a minimum number of unique Pfam domains and includes at least one user-specified "core" Pfam. The script calculates a score for each valid cluster and generates two output files: a detailed TSV listing all genes within each cluster, and a summary TSV with high-level statistics for each cluster. The script requires Python 3 and the tqdm library for progress visualization.

**casette_search_gff.py**: command-line utility designed to augment gene annotation data by merging information from two different sources. It takes a TSV file containing gene IDs and their associated Pfam domains and cross-references it with a directory of GFF files named by genome ID. For each gene from the input TSV, the script searches the corresponding GFF file to find and extract its genomic coordinates and other attributes. This combined information is then written to a new, comprehensive TSV output file. The script requires Python 3 and the tqdm library for its operation and creates a detailed log file to track the process.

**casette_search_retreive.py**: command-line tool designed to enrich gene cluster data by retrieving genomic details from GFF files. It takes a TSV file containing cluster, genome, and gene IDs as input and searches a specified directory of GFF files to find matching gene entries. A key feature is its hybrid search capability, which correctly handles both simple numeric gene IDs and complex identifiers containing underscores. The script then merges the cluster information with the corresponding GFF data (such as sequence ID, start/end coordinates, and strand) and writes the consolidated results to a new output TSV file, while also generating a detailed log of the process. The script requires Python 3 and the tqdm library.

**operon_visualization_tool.py**: command-line tool for creating interactive HTML visualizations of gene clusters from a GFF-like file. It represents genes as arrows, arranged according to their genomic positions, and intelligently colors them based on a hierarchy: first by user-defined marker genes, then by the dominant protein domain identified from an optional jackhmmer results file, and finally with a default color. The script can also display bars above genes to indicate specific domain regions. The final output is a self-contained HTML file with legends and clickable genes for easy copying of IDs. The tool requires Python 3 and the pandas library.

**get_taxonomy_by_cluster.py** : a command-line utility designed to extract and append taxonomic information to lists of cluster IDs. The tool reads all cluster IDs from files ending in _sorted_unique within a specified directory, then searches for these IDs in a large TSV database. It retrieves the corresponding taxonomic data from a user-specified column in the database and generates a new TSV file for each input file, containing the cluster IDs and their associated taxonomic information. This script requires only Python 3 and its standard libraries to run.

**genes_per_cluster.py**:  a command-line tool that analyzes the distribution of a specific list of genes across different clusters. It takes a file containing gene-to-cluster assignments and a separate list of target genes, then counts how many target genes appear in each cluster. The script outputs a detailed summary to the console, including statistics like the number of clusters with a certain number of genes, and also generates new files containing comma-separated lists of clusters that have exactly 1, 2, 3, or 4 of the target genes. The script requires only Python 3.

**retreive_NCBI_taxa.py**: a command-line tool that retrieves the full taxonomic lineage for a list of NCBI Taxonomy IDs (TaxIDs). It reads a file of TaxIDs, queries the NCBI Taxonomy database in batches, and for each TaxID, it fetches the lineage from superkingdom down to the species level. The results are compiled into a tab-separated (TSV) file with each row containing the TaxID and its complete taxonomic classification. The script requires Python 3, Biopython, and the tqdm library for progress bars.

**retreive_pfam_interpro.py**: a command-line tool for fetching all UniProt protein accessions and their corresponding NCBI taxonomy IDs for a given list of Pfam domains. It reads Pfam IDs from an input file, queries the EBI InterPro API for each one, and systematically paginates through all results to ensure complete data retrieval. The script is designed for robustness, featuring progress bars, error handling, and request retries. For each Pfam ID provided, it generates a separate tab-separated (TSV) output file containing the collected protein accessions and taxonomy IDs. The script requires Python 3 and the tqdm library.

**retreive_taxonomy_by_pfamIDs.py**: a command-line tool that analyzes the kingdom-level taxonomic distribution (Bacteria, Archaea, Eukaryota, Viruses) for proteins containing specific Pfam domains. It takes a file of Pfam IDs, queries the EBI InterPro API to get taxonomic data, and calculates the percentage of each kingdom for every Pfam domain. The script prints a summary breakdown to the console and can optionally save the detailed results to a JSON file. It requires Python 3 and the requests library.

**substructure_extrations.py**: a command-line tool that extracts specific structural regions from protein PDB files based on coordinates and a quality score provided in a TSV file. It reads the input TSV, filters entries based on a minimum Domain-Specific Score (DSS), and for each qualifying entry, it locates the corresponding PDB structure. It then uses Biopython to parse the structure and save a new PDB file containing only the amino acid sequence within the specified start and end coordinates. The script requires Python 3, pandas, Biopython, and tqdm.

**3d_domain_tool_1.5.py**: a command-line tool for de novo structural domain identification from protein PDB files, particularly those from AlphaFold. It operates by first determining secondary structure elements (helices and sheets) using DSSP. It then constructs a graph where these elements are nodes, and an edge is created between any two nodes that have close spatial interactions. The connected components of this graph are identified as structural domains. For each domain, the script calculates the residue boundaries and the average pLDDT score (B-factor), outputting these results to a TSV file. The script can process a single PDB file or run in batch mode on a directory of files and requires Python 3, Biopython, and NumPy.

**3d_max_distance.py**: is a command-line tool that analyzes structural properties from a directory of PDB files. For each structure, it calculates the total amino acid chain length and the "fiber length" (the maximum C-alpha to C-alpha distance), saving the results to a TSV file. The script then generates a scatter plot to visualize the relationship between these two metrics. A key feature is its ability to read protein group definitions from an external directory to color-code the data points on the plot, making it easy to compare different protein families. This tool requires Python 3, pandas, NumPy, Matplotlib, Biopython, and tqdm.

**analyse_enrichment_in_phyla.py**: 
a command-line tool that performs a phylum-level enrichment analysis to determine if multi-gene clusters are more prevalent in certain phyla compared to single-gene clusters. It reads a file containing cluster and taxonomic data, uses Fisher's Exact Test to calculate statistical significance (p-value and odds ratio) for each phylum, and then generates three outputs: a detailed TSV file with the results, an informative dot plot, and a diverging bar plot to visualize the enrichment or depletion. The script requires Python 3, pandas, NumPy, Matplotlib, and SciPy.
